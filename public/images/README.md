## 統一風格 Prompt 前綴

在所有 DALL-E 3 prompt 前加上這段，確保風格一致：

```
台灣心理懸疑風格，電影攝影感，去飽和色調（深灰、炭黑、霧白），
不要文字，不要 logo，無人物正臉特寫，
cinematic psychological thriller, desaturated, atmospheric fog
```

---

## 圖片格式建議

- 格式：WebP（品質 85）
- 場景圖尺寸：1080×720 px（橫向）
- 角色立繪尺寸：400×600 px（直向）
- 線索物件：600×400 px
- 記憶碎片：1080×720 px（黑白處理）

如果你用 ChatGPT 生成，右鍵下載後用 [Squoosh](https://squoosh.app) 轉成 WebP 格式。
