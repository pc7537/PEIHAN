# 9:16 短影音自動剪輯 SOP

> 把原始影片丟給 Claude Code，自動輸出直式短影音。

---

## 工具清單

| # | 功能 | 工具 | 安裝 |
|---|------|------|------|
| 1 | 錄音轉文字 | Whisper | `pip install openai-whisper` |
| 2 | 自動快剪 | Auto-Editor | `pip install auto-editor` |
| 3 | 裁切 9:16 | ffmpeg | `brew install ffmpeg` |
| 4 | 燒錄字幕 | ffmpeg + SRT | （同上） |
| 5 | 加標題字卡 | ImageMagick + ffmpeg | `brew install imagemagick` |
| 6 | 配樂混音 | ffmpeg | （同上） |
| 7 | 找 B-roll | Pexels API | 申請 key → [pexels.com/api](https://www.pexels.com/api/) |

> [!note] 備註
> 作者不裝 ElevenLabs，因為偏好自己錄音，步驟 7（B-roll）也是可選項。

```bash
# Python 工具
pip install openai-whisper auto-editor requests

# macOS
brew install ffmpeg imagemagick

# Ubuntu / Debian
apt install ffmpeg imagemagick
```

## 流水線腳本

腳本位置：`scripts/clip.sh`

```bash
# 基本用法
./scripts/clip.sh raw.mp4

# 加標題字卡 + 背景音樂
./scripts/clip.sh raw.mp4 "Claude Code 真的太猛" bg_music.mp3
```

輸出在 `output/<檔名>/` 目錄，最終檔案為 `*_final.mp4`。

## 六步流程說明

### Step 1 — Whisper 語音轉文字

```bash
whisper raw.mp4 --model small --language zh --output_format srt --output_dir output/
```

- 產出 `.srt` 字幕檔
- 建議 model：`small`（速度快）或 `medium`（精確）

### Step 2 — Auto-Editor 自動快剪

```bash
auto-editor raw.mp4 --silent-threshold 0.04 --margin 0.2sec --output autocut.mp4
```

- 自動去掉靜音、NG、贅詞
- `--silent-threshold 0.04`：低於 4% 音量視為靜音

### Step 3 — ffmpeg 裁切 9:16

```bash
ffmpeg -i autocut.mp4 \
  -vf "scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920" \
  -c:v libx264 -preset fast -crf 23 \
  916.mp4 -y
```

- 輸出 `1080×1920`，適合 IG Reels／YT Shorts／TikTok

### Step 4 — ffmpeg 燒錄字幕

```bash
ffmpeg -i 916.mp4 \
  -vf "subtitles='output.srt':force_style='FontSize=18,Bold=1,Outline=2,Alignment=2,MarginV=60'" \
  subbed.mp4 -y
```

- 字幕硬燒進影片，任何平台都顯示

### Step 5 — ImageMagick + ffmpeg 標題字卡

```bash
# 產生標題圖片
convert -size 1080x1920 xc:black \
  -gravity Center -fill white -pointsize 72 \
  label:"你的標題" title_card.png

# 合併到影片開頭（2 秒）
ffmpeg -loop 1 -t 2 -i title_card.png -i subbed.mp4 \
  -filter_complex "[0:v][1:v]concat=n=2:v=1:a=0[v]" \
  -map "[v]" -map "1:a" titled.mp4 -y
```

### Step 6 — ffmpeg 配樂混音

```bash
ffmpeg -i titled.mp4 -i bg_music.mp3 \
  -filter_complex "[1:a]volume=0.15[bg];[0:a][bg]amix=inputs=2:duration=first[a]" \
  -map "0:v" -map "[a]" \
  final.mp4 -y
```

- 背景音樂音量自動壓低至 15%，不蓋過人聲

## B-roll 下載（可選）

需先申請 [Pexels API Key](https://www.pexels.com/api/)。

```bash
export PEXELS_API_KEY="你的金鑰"
python scripts/pexels_broll.py "科技 辦公室" --count 3 --outdir broll/
```

自動下載直式（9:16）B-roll 素材到 `broll/` 目錄。

## 常見問題

> [!warning] 字幕燒錄失敗
> 通常是字型問題。安裝 `noto-fonts-cjk` 或改用系統已有字型。

> [!tip] 橫式影片自動裁切
> ffmpeg 的 `force_original_aspect_ratio=increase,crop` 會優先保留畫面中央，直播或訪談影片建議手動指定裁切位置 `crop=1080:1920:x:y`。

> [!tip] Whisper 跑很慢
> 加 `--device cuda`（需 NVIDIA GPU）或改用 `--model tiny` 快速模式。
